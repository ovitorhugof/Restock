# Recanto Sabor de Minas — demonstração local

## Abertura rápida

- Dê dois cliques em `INICIAR-SISTEMA.bat` para abrir o controle de estoque e habilitar o acesso ao terminal pelo menu.
- Dê dois cliques em `ABRIR-TERMINAL-DE-MESAS.bat` para abrir o terminal da recepção.

O sistema funciona localmente: estoque, movimentações e identificação são guardados no navegador. O terminal de mesas usa o arquivo `terminal/mesas.json`.

## Roteiro de apresentação

1. Entre com seu nome.
2. Mostre os alertas do painel.
3. Cadastre um produto em **Produtos**.
4. Registre uma entrada ou saída em **Movimentar estoque**.
5. Abra **Histórico** para mostrar responsável, data e observação.
6. Clique em **Terminal de mesas ↗**: o terminal original abre em uma janela separada e a aba de confirmação pode ser fechada.

## Limites atuais

Não há banco de dados ou hospedagem. O acesso usa uma senha fixa para a demonstração e os dados são isolados por navegador, sem compartilhamento entre computadores.
